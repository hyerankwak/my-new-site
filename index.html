쿠파스 자동 연결 방향

1. 정적 사이트만으로는 한계

GitHub Pages는 공개 HTML이라 쿠팡 API Secret Key를 넣으면 안 됩니다.

2. Cloudflare Worker 필요

Worker에 API 키를 환경변수로 저장하고, 사이트는 Worker API만 호출해야 안전합니다.

3. 상품 사진 자동 표시

쿠팡 API 응답의 상품 이미지 URL과 파트너스 링크를 카드에 자동으로 넣는 구조가 좋습니다.

토이포포상품 가격과 배송 정보는 쿠팡 상세 페이지에서 확인해주세요.
